<h1 align="Center">PolyLife</h1>

> 🚧 Still under development.
<p>A 3d Low-poly survival game.</p>

<h2 align="left">Description</h2>

<p>This is a game I created to learn about LÖVR (Lua Framework). This project still under development, not fully done yet.</p>

<h2 align="left">How to run (If interested)</h2>

- <h3>Clone this repository</h3>

```bash
git clone https://github.com/003-aldienhw/PolyLife.git
```

- <h3>Go to the root folder</h3>

```bash
cd PolyLife
```

- <h3>Run the game</h3>

```bash
lovr PolyLife
```
